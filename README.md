# 🛍️ Análise de Vendas de 5 Lojas — Python + Pandas

Este projeto tem como objetivo realizar uma análise completa de dados de vendas de 5 lojas distintas com base em arquivos CSV. A partir da importação e tratamento dos dados, aplicamos diversas métricas para entender o desempenho de cada loja e identificar qual oferece a melhor experiência de compra.

---

## 📊 Objetivos da Análise

- ✅ Importar e consolidar os dados das 5 lojas.  
- 💰 Calcular o faturamento líquido total por loja.  
- 🏷️ Analisar as vendas por categoria (quantidade e valor).  
- ⭐ Calcular a média das avaliações de compra por loja.  
- 🛒 Identificar os produtos mais e menos vendidos por loja.  
- 🚚 Calcular o frete médio por loja.  
- 🏆 Determinar qual loja oferece o melhor custo-benefício ao consumidor.  

---

## 🧪 Tecnologias Utilizadas

- Python 3  
- Pandas  
- Google Colab (ou Jupyter Notebook)  

---

## 📈 Principais Resultados

As lojas foram analisadas individualmente e comparadas entre si com base em indicadores de performance como faturamento, frete médio, avaliações e comportamento de vendas por produto e categoria.  

A análise permitiu observar padrões e identificar **qual loja entrega a melhor combinação entre preço, frete e satisfação do cliente**.
